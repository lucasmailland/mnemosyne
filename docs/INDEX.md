## Package Map

| Package                                                   | Role                                                                                                                                                                                                                                                           |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@mnemo-ai/types`                                         | Zero-dependency TypeScript interfaces, enums, constants, and port definitions. Every other package imports from here; nothing imports into here.                                                                                                               |
| `@mnemo-ai/core`                                          | Pure business logic: recall orchestration, consolidation, worth scoring, graph traversal, session collapse. Zero infrastructure imports — receives all adapters via dependency injection.                                                                      |
| `@mnemo-ai/adapter-postgres`                              | PostgreSQL storage adapter implementing the `StorageAdapter` port from types. Owns all SQL, migrations, and RLS policy setup.                                                                                                                                  |
| `@mnemo-ai/adapter-redis`                                 | Redis cache adapter implementing the `CacheAdapter` port. Provides hot-tier, session buffers, and rate-limit backing. Gracefully degrades to in-memory LRU when absent.                                                                                        |
| `@mnemo-ai/adapter-vector`                                | pgvector (and future Qdrant) adapter implementing the `VectorAdapter` port. HNSW index management, embedding upserts, cosine similarity search.                                                                                                                |
| `@mnemo-ai/adapter-llm`                                   | Bridge adapter that wires `llm-providers` concrete implementations into the `LLMAdapter` port expected by core.                                                                                                                                                |
| `@mnemo-ai/llm-providers`                                 | Concrete LLM/embedding provider implementations (7): OpenAI, Anthropic, Google, Cohere, Mistral, Voyage, Ollama — plus an `LLMRouter` (per-task dispatch) and a `BudgetGuard`.                                                                                 |
| `@mnemo-ai/server`                                        | Hono HTTP server exposing the REST API. Auth middleware, rate limiting, route handlers, OpenAPI schema. Composes core + all adapters.                                                                                                                          |
| `@mnemo-ai/mcp`                                           | MCP server (37 tools; `MNEMO_MCP_TOOLS=core` trims to 9) over stdio, a separate process that calls the server's REST API. Workspace-scoped by API key. Recalled skills and workflows are surfaced through the static `memory_skill` / `memory_workflow` tools. |
| `@mnemo-ai/client-ts`                                     | Typed TypeScript HTTP client for the REST API. Generated from the OpenAPI spec. For use by external consumers.                                                                                                                                                 |
| `@mnemo-ai/cli`                                           | `mnemo` CLI binary; every command is in [guides/CLI.md](guides/CLI.md). Talks to the server via HTTP. Shell completion for bash/zsh/fish/pwsh.                                                                                                                 |
| `@mnemo-ai/consolidation`                                 | Background "sleep cycle" consolidation (BETA): 6-condition gate + replay validator; `startConsolidationScheduler()` runs on an interval, wired at server boot.                                                                                                 |
| `@mnemo-ai/cup`                                           | Cognitive Upgrade Protocol — the v2→v3 schema migration toolkit (`TypeMapper` maps legacy memory types onto the 10 primitives). Keyset-cursor CLI ingestion runner in `migrate.ts` (Wave V7).                                                                  |
| `@mnemo-ai/federation`                                    | Cross-instance sync (BETA): `SyncEngine`, mTLS auth, 9 HTTP routes, LWW conflict resolution, resurrection + version-inflation guards. Pull transport implemented (`PullClient.ts`).                                                                            |
| `@mnemo-ai/plugins`                                       | In-process plugin runtime (STABLE): `PluginLoader` loads `package:` plugins from config and is wired at server boot. In-process plugins run as fully-trusted server code (no sandbox isolation).                                                               |
| `@mnemo-ai/mock-server`                                   | Offline fixture server for local dev and testing (AB6). Provides a lightweight HTTP server that mimics the real server's API surface without requiring a database.                                                                                             |
| `mnemo-ai-sdk` (Python)                                   | Sync `MnemosyneClient` + async `AsyncMnemosyneClient` (httpx). Full method parity with the TS SDK across 80+ endpoints. Python 3.9+.                                                                                                                           |
| `github.com/lucasmailland/mnemosyne/packages/sdk-go` (Go) | Zero-dependency Go SDK (stdlib `net/http` only). Full method parity with TS/Python SDKs.                                                                                                                                                                       |
